# SORAJA ENGINE

Pusat komando agen AI coding untuk desktop. Jalankan Claude Code, Codex, Antigravity, OpenCode, dan Kiro dengan akun Anda sendiri, lihat setiap langkah kerja agen, tinjau perubahan kode, lalu pulihkan berkas bila hasilnya kurang pas.

Repo ini hanya berisi **rilis** aplikasi (installer dan catatan rilis). Kode sumber aplikasi tidak dipublikasikan.

## Unduh

- Halaman unduhan: buka web SORAJA ENGINE, atau
- Pilih versi terbaru di [Releases](../../releases/latest): `.exe` / `.msi` (Windows), `.dmg` (macOS), `.AppImage` / `.deb` / `.rpm` (Linux).

Aplikasi yang sudah terpasang memperbarui dirinya sendiri. Pembaruan diverifikasi tanda tangannya sebelum dipasang.

## Laporkan masalah

Buka [Issues](../../issues) dan sertakan versi aplikasi (Pengaturan → Data & Bantuan), sistem operasi, serta langkah untuk mengulangi masalahnya.
